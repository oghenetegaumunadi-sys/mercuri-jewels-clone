# Mercuri Jewels Landing Page

A lightweight, responsive ecommerce landing page inspired by the provided luxury jewelry mockup.

## Local preview

Open `index.html` directly in a browser, or serve the folder with a static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — page structure
- `styles.css` — styling and layout
- `script.js` — hero slider interactivity

## Notes

This implementation uses public Unsplash imagery and a static front-end stack so it is easy to customise and deploy.
